# Internal DevOps Utilities Api

## Aims

This project aims to deliver production grade utilities API to internal teams
- AWS Resources APIs
  - Show old buckets
  - get EC2 Inventory
  - Get Unattached volumes
  - Check security groups
- System Metrics

## Usage
git clone <repo>  

### setup the python environment  

python3.14 -m venv venv  
source venv/bin/activate  

### install the requirements  
pip install -r requirements.txt  

### run the application  
python main.py
